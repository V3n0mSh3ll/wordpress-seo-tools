# WordPress Technical SEO & Web Performance Utilities

A curated reference of browser-based utilities and technical checklists for auditing WordPress websites, Core Web Vitals, and structured data markup. Maintained by the engineering team at [GrowthNiq](https://growthniq.com/).

## Free Browser Utilities

All tools run directly in the browser with no registration required:

- **[WordPress Theme & Plugin Detector](https://growthniq.com/theme-detector/)** — Inspect active themes, child themes, and frontend plugins on any WordPress site.
- **[Schema Markup Generator (JSON-LD)](https://growthniq.com/schema-generator/)** — Generate valid Article, FAQPage, SoftwareApplication, and BreadcrumbList structured data.
- **[Google SERP Snippet Simulator](https://growthniq.com/serp-simulator/)** — Preview desktop and mobile pixel truncation for <title> and <meta name="description">.
- **[Robots.txt Generator](https://growthniq.com/robots-generator/)** — Build clean crawler directives for Googlebot, Bingbot, and AI search crawlers.
- **[XML Sitemap Generator](https://growthniq.com/sitemap-generator/)** — Generate standards-compliant XML sitemaps with ISO-8601 <lastmod> timestamps.
- **[SEO Headline Analyzer](https://growthniq.com/headline-analyzer/)** — Evaluate blog titles for length, clarity, and click-through rate.
- **[Keyword Density Checker](https://growthniq.com/keyword-density/)** — Check 1-word, 2-word, and 3-word phrase frequency in draft articles.
- **[Readability Score Checker](https://growthniq.com/readability-checker/)** — Calculate Flesch-Kincaid reading ease and sentence complexity.
